# Montblanc Eventfotos

Hier können freigegebene, für die Webseite optimierte Fotos vom Baukarussell Montblanc Event abgelegt werden.

Die Dateien sind öffentlich im GitHub Repository sichtbar. Das Hochladen allein veröffentlicht die Fotos noch nicht auf der Eventseite. Die Bilder müssen danach mit der Eventgalerie verknüpft werden.
